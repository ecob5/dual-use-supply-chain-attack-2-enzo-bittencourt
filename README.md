## 🎯 Supply Chain Attack Implementation

### What Is a Supply Chain Attack?

A supply chain attack occurs when an attacker compromises third-party components to infect legitimate software. In this exercise:

* We compromise the Currency Exchange repository
* We add our own malicious code (backdoor)
* The backdoor performs logging and collects fingerprints

### Backdoor Implementation

The backdoor will be implemented as a Python module that:

1. Intercepts the execution of the main code
2. Adds automatic logging
3. Collects hardware/software fingerprints
4. Checks the target hostname
